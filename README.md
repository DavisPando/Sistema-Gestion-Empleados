# Sistema-Gestion-Empleados 

Sistema desarrollado en C# con WinForms para gestionar empleados de una empresa.

## Tecnologías utilizadas
- C# .NET Framework 4.7.2
- Windows Forms
- LINQ
- Visual Studio
- Git & GitHub

## Funcionalidades
- Registro de empleados
- Aplicación de bonos
- Descuento IESS 9.45%
- Consultas con LINQ
